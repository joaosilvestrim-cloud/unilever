# Unilever · Plataforma de Gestão de Projetos

Mockup de alta fidelidade (protótipo navegável) da plataforma de gestão de projetos Unilever, para apresentação ao cliente.

## Stack

Site estático — um único `index.html` autocontido (HTML/CSS/JS inline, fontes via Google Fonts). Sem build, sem dependências.

## Deploy

Importar este repositório no [Vercel](https://vercel.com) como projeto estático (framework preset: **Other**). Nenhuma configuração adicional é necessária.

## Desenvolvimento local

Basta abrir `index.html` no navegador.
